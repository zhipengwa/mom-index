# 历史样本口径文案设计

## 目标

将宝妈指数的公开表述统一限定为对历史公开样本的描述。保留指数、讨论热度和买入/卖出表达统计，但不提供价格预测、投资品种选择、买卖时机或仓位建议。

## 展示口径

- 指标统一称为“公开样本讨论热度”。
- “宝妈买入/卖出”改为“样本买入表达/样本卖出表达”。
- “买卖比”改为“样本表达比”。
- 高、中、低分级只说明样本讨论活跃度，不使用“危险信号”“市场底部”“减仓”“追涨”“恐慌”等预测或操作导向措辞。
- 页面显著说明：“指标只描述历史公开样本中的讨论，不代表全体投资者；不具备价格预测或投资品种选择功能。”

## 修改范围

同步修改计算器解释文案、前端标题与说明、README、演示 JSON 数据及其前端副本。不得改动指数计算公式、数据结构或图表逻辑。

## 验证

在现有公开框架测试中新增文案约束：要求核心说明存在，并禁止预测或操作导向词出现在面向用户的项目文件中。测试应先因现有文案失败，再通过最小代码和内容修改转为通过；最后运行完整测试并搜索残留措辞。
