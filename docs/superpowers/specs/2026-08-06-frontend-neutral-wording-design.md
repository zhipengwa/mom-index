# 宝妈／宝爸指数前端中性化文案设计

## 目标

将宝妈指数和宝爸指数所有面向用户的前端文案统一限定为“历史公开样本讨论热度”和“文本表达统计”。页面继续展示现有指数、变化值和比例，但不得把这些数值描述为真实成交、持仓、资金流、价格位置、风险信号或投资机会。

## 修改范围

- 修改宝妈指数当前浅色前端。
- 修改宝妈指数公开发布前端。
- 修改宝爸指数公开发布前端。
- 只修改前端 HTML、CSS 和前端渲染文案。
- 不修改采集器、LLM 分类、指数算法、数据文件、历史记录或数据结构。

## 文案规则

### 指标定义

页面显著说明：

> 指标基于历史公开帖子和评论中的文本表达进行聚合，只描述公开样本的历史讨论热度，不代表全体投资者，也不是实际成交、持仓或资金流数据；不具备价格预测、投资品种选择或买卖时机建议功能。

### 状态分级

前端不得直接展示数据文件中的 `interpretation` 字段。状态仅按现有数值映射为中性热度描述：

- 0–20：样本讨论热度较低
- 20–40：样本讨论热度偏低
- 40–60：样本讨论热度中等
- 60–75：样本讨论热度较高
- 75–100：样本讨论热度很高

### 标签替换

- “板块情绪脉搏”改为“板块讨论热度”。
- “买卖结构”改为“文本表达结构”。
- “买入”改为“买入表达”。
- “卖出”改为“卖出表达”。
- “买卖比”改为“样本表达比”。
- “科技指数”改为“科技话题样本热度”。
- “老登指数”改为“宝爸主题样本热度”。
- “机会观察区”“风险警戒区”“高度警惕”“极度狂热”“极度冷清”等评价性词语改为对应的中性讨论热度区间。

## 渲染与兼容

页面保持现有布局、颜色、图表、排序和响应式行为。历史 JSON 即使仍包含旧解释，前端也必须忽略这些解释并使用中性映射，以避免旧数据或后续数据重新带出风险、机会或操作导向文字。
